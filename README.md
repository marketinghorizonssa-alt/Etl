# Etlala Performance Site

GitHub is the source of truth for the new Etlala landing-site rebuild.

## Current architecture
- Static Arabic-first multi-page site generated by `build.mjs`.
- Preserves the requested destination URL structure.
- Site-side dataLayer events: `whatsapp_click`, `call_click`, `form_submit`.
- Includes `robots.txt`, `sitemap.xml`, `llms.txt`, TravelAgency schema and FAQ schema.
- No framework/runtime dependencies, intentionally optimized for Lighthouse and Google Ads landing-page quality.

## Deployment
Run `npm run build`; output is generated in `dist/`.
Deploy the repository through Hostinger Git integration. Do not switch production DNS until the new copy is validated.

## Targets
- Lighthouse Performance: 100 target
- Accessibility: 100 target
- Best Practices: 100 target
- SEO: 100 target
- Google Ads landing-page quality: maximize message match, speed and conversion clarity
- Agentic/AI discoverability: structured data, `llms.txt`, canonical URLs and clean semantic HTML

Actual scores must be measured on the final production build after all real images and production scripts are installed.
